# 特殊长者 · 智能手环端 需求记录

> 版本：新增角色需求（在既有「长者端 / 子女端」之外，追加第三类移动端角色）
> 范围：账号体系 + RBAC + APP 端原型 + 小程序端原型 + 后台数据联动

## 一、背景与目标

部分长者**不识字（文盲）**或**不方便操作智能手机**（认知轻度障碍、手部不便、视力差等），
无法使用现有信息密度高的「长者端」。这类长者需要配备一枚**极简智能手环**，
手环端只保留 5 项能力，做到「零文字、大图标、语音 + 震动」：

1. **时间**：超大数字显示，整点震动报时。
2. **震动**：吃药 / 活动 / 吃饭前震动 + 语音播报提醒，无需任何操作。
3. **SOS**：长按一键呼救，直连值班医护、门禁、房间大屏与子女端。
4. **自动打卡**：长者到达园区内的特殊位置（餐厅、理疗室、活动室、花园、医务室等）时，
   手环通过蓝牙 / GPS 围栏**自动完成签到打卡，并自动参加对应活动**，全程无需手动操作。
5. **播报**（底部按钮，增量需求）：一键**语音播报当前时间、所在位置、当前天气**，
   配合震动确认；位置优先取最近一次自动打卡点。底部标签栏由此变为 5 项，SOS 居中对称：
   `手环 · 打卡 · SOS · 播报 · 我的`。

## 三、APP / 小程序原型（手环端）

在 APP 端与小程序端原型左侧的角色切换中，新增「手环端」按钮；进入后手机壳内呈现手环风格界面：

- **手环主屏**：超大时钟 + 日期星期 + 所在区域；电量 / 连接 / 定位状态；
  今日自动打卡进度（图标点亮）；下一站预告；震动提醒卡片；超大 SOS 按钮 + 呼叫家人 + 震动测试。
- **自动打卡页**：列出特殊位置（康养餐厅 / 康复理疗室 / 文化活动室 / 银杏大道 / 医务室），
  每项标注时间与关联活动；「模拟到达」触发自动打卡（也可「一键演示全部到达」）。
- **我的页**：手环设备信息、四项功能说明、紧急联系人、语音播报 / 大字体开关、返回门户 / 退出。

## 四、自动打卡的业务联动（写入同一份数据，后台实时可见）

长者到达某特殊位置时：

1. 手环震动 + 语音确认（toast 提示）；
2. 若该位置关联活动（如「合唱团社区联排」「中医理疗」），对应活动 `签到人数 +1`；
3. 写入一条 `健康与病例档案 → 护理记录`：「手环自动打卡：到达 XX，自动签到活动《YY》」；
4. 银杏大道打卡额外增加步数；
5. 记录操作日志（`手环自动打卡`）。

SOS 与亲情呼叫复用既有告警联动：写入 `设备告警`、推送大屏与子女端、生成操作日志。

## 五、验收标准

- 用 `special / 123456` 登录后进入 APP 端 / 小程序端，默认显示手环端界面；
- 手环主屏时钟、打卡进度、SOS、呼叫、震动测试均可交互；
- 「模拟到达 / 一键演示全部到达」后：后台对应活动签到 +1、健康档案新增护理记录、门户待办 / 大屏联动更新；
- admin 等账号可在角色切换中手动切到「手环端」体验同一原型；
- 不新增后端，全部数据存于内存 + localStorage，「重置演示数据」可还原。
